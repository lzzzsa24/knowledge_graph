# 历史 PDF 图文入库与断点恢复

此队列处理已登记的 216 份本地原始 PDF，复用 5 份已有原生索引，其余 211 份按 [队列顺序](queue.json)处理。抽取使用 Codex CLI 的 ChatGPT 订阅、GPT‑6.2 Sol、High 推理强度。同一工作区共享 12 个模型请求名额，整批核验后提交正式图谱。

后续文献逐页核对旧阅读副本与原始 PDF 的指纹、页码和质量记录。质量合格的页沿用原文，缺字、待复核或空文本页从原页图补识别。图、表和独立公式均从原 PDF 定位和裁取。每篇的 `mixed-parse.json` 记录正文来源和物理页，`pdf-regions.json` 记录图表公式的页码、裁剪坐标和图像指纹。切换流程时，已发布论文按原清单保留，处理中论文可复用输入完全相同的模型响应。

入库的 BGE-M3 设备按批读取 `embedding_backend.json`。CUDA 编码使用项目的 `.venv-bge-gpu` 共享进程，沿用同一模型修订、FP32 精度、512 token 上限和归一化设置。共享的 `documents/_workspace/embedding_run.json` 记录设备和向量化耗时，发布记录保存批次耗时。查询使用 CPU 编码。设备设置在下一批生效。

单篇的问题页、公式及缺少可用单元格文字的表格共用 6 个转写名额，页面裁图审核每篇最多并发 4 项。结果按原 PDF 的页序入库。`mixed-parse.json` 的 `transcription` 记录任务数、并发峰值和经过时间。无图注、无脚注的图片先核对已审阅的装饰图指纹，再与已审阅图样的宽高比及整幅图案比对，以识别留白或缩放略有变化的同一标志。表格、公式和未匹配的图片继续入库。跳过的原图、物理页、坐标、指纹及原因保存在 `skipped_decorations` 中。

入库页的“查看裁图”可核对当时参与入库的区域和已过滤的装饰。新规则命中历史入库项时，页面另列当前可过滤的项目。早期已发布论文的图片来自旧版解析档案；当时仅保存内容的表格、公式，预览使用旧版版面坐标从同一修订的原 PDF 补绘。需要恢复这些预览时运行 `scripts/restore_native_gallery.py`，结果存入独立的 `legacy_gallery` 目录。

## 裁图与按页审核

本机已安装裁图工具。迁移到新机器时，安装 JDK 并在项目根目录运行 `python scripts/setup_native_crop_tools.py`。PDFFigures 2 和 Docling 分类器保存在 `pilot/model_cache/crop-tools`。

入库优先复用与本地 PDF 校验一致的 PMC 图文件和结构化公式。缺图、并框时，程序结合独立解析器和原页图框补裁。原页与编号框叠图一起提交给订阅模型，每个风险页审核一次，另抽一个普通页，修正后的裁图再审核。带有问题记录的文献自动进入针对原问题的复核，存量文献也适用。相同输入复用响应检查点。同版 PDF 的复核仍有疑点时保留具体问题，队列继续处理其他文献。

文献入库页的“查看裁图”可查看保留项、过滤原因、审核页码和待复核问题。每篇的 `crop-review.json` 保存页审结果和原页位置，`mixed-parse.json` 保存实际送入索引的内容。

只做裁图验收时，在指定文献的命令后加 `--crops-only`。例如在项目根目录运行：

```powershell
.venv/Scripts/python.exe scripts/run_native_library.py --only journals_mi15111332 --crops-only --concurrency 2
```

原页裁图与视觉审核完成后即可在网页查看。这个入口写入裁图和页审检查点，后续正式入库会复用通过的同版结果。已有指定文献在发布时，裁图任务使用该并行上限中剩余的名额。

## 正式队列的共享工作区

全队列已暂停时，可使用同一个调度脚本只发布指定文献：

```powershell
.venv\Scripts\python.exe -X utf8 scripts/run_native_library.py --only journals_ma18225152 --concurrency 1
```

`--only` 可接受多个文献 ID；需要锁定版本时使用 `ID@完整SHA256`。调度器在启动任何一篇前核对整组 PDF，复用既有审核与索引检查点，跳过已发布的同版文献。`--concurrency` 只控制本次任务，主索引始终由一个发布进程写入。全队列的暂停标记会保留；运行中再次点击暂停，会停止本次任务。每次的发布结果记录在 `selected-runs` 目录。

正式队列以页面保存的并行数为每批上限，支持 1–4 篇。单个进程加载最新已发布快照的副本，在同一个 RAG-Anything 工作区并行插入本批文献，每篇调用一次原生入库入口。同批通过预处理的文献先一起进入 LightRAG 的正文队列，再启动索引。整批核验后原子切换发布清单。在入库前遇到裁图待复核的文献会暂留，其他已核验的文献可以共同发布。失败的索引插入可能留下部分图谱，整批会保留旧发布快照以便恢复。

切换时可复用原有解析、裁图审核、相同输入的模型响应和向量缓存。后续共享工作区的响应和向量检查点保存在 `documents/_workspace`。工作区共用最多 12 个模型请求名额和一个本机向量编码进程。并行设置在下一批生效。

预处理依次完成裁图审核、修正页复审、原文解析及验收。验收核对物理页码、正文指纹、裁图文件以及表格和公式的转写。通过后在每篇的 `preflight.json` 记录裁图复核和解析检查点的指纹，网页将它列为“已验收，待正式入库”。正式建索引只读取已验收的输入。PDF 版本、裁图或解析变更后重新走预处理。正式批次建索引时，独立的预处理进程可以继续复核存量问题并准备下一批。它只保存文献检查点，主索引仍由正式批次独占写入和核验发布。

全队列设为 2 篇时从已验收池自动配对。先选当前优先级最早的一篇，从其后最多 15 篇候选中选取预计剩余工作量最接近的一篇。估算依据包括同版本的正文、裁图与解析检查点、缺失文字页和图表公式数量。日志的 `PAIR WORK ESTIMATES` 是用于排序的相对分值。指定文献和已约定的试跑组沿用指定范围，并经过相同验收。

运行 `--status` 可查看 `queue_lanes` 中当前工作的文献，`scheduler.json` 记录正在处理的 ID。暂停或额度重置后依据正式发布清单跳过已发布文献，依据各篇检查点继续其余文献。

## 停电前与来电后

1. 双击[暂停文献入库](../../../暂停文献入库.cmd)，让窗口保持打开。暂停请求会保存在磁盘上，正在进行的调用有时间返回并保存。
2. 窗口显示 **已暂停，可关机** 后，即可关机。此时队列调度与索引写入锁都已释放。
3. 来电后双击[继续文献入库](../../../继续文献入库.cmd)，保持继续窗口打开。遇到突然断电，也从这个入口恢复。它会校验最近发布的索引，跳过已完成文献，并从队列中下一份待处理资料开始。

当前论文可以复用已保存的 PDF 解析结果和输入相同的模型响应。模型已接收、但响应尚未保存的请求可能再次消耗订阅额度。尚未提交的本地向量化、图谱合并和写盘会从最近的正式快照重新执行。恢复流程已通过模拟工作进程强制退出测试；机器本身的磁盘故障可能仍需使用备份。

## 本地进度与检索

在项目根目录的 PowerShell 中运行以下命令。状态查询和向量检索都不调用云端模型。

```powershell
.venv/Scripts/python.exe -X utf8 scripts/run_native_library.py --status
.venv/Scripts/python.exe -X utf8 scripts/run_native_library.py --search "铜键合后的晶粒尺寸"
```

[发布清单](manifest.json)记录已提交的 PDF 指纹与索引位置。[当前文献](current.json)记录最近的开始、完成或中断情况。进程意外退出时，当前文献文件可能还保留最后一次运行状态，恢复入口以通过校验的发布清单为准。每篇的解析和模型调用检查点在 `documents/<文档 ID>/`。

继续入口会检查订阅窗口。如果额度已用尽且服务返回了明确的重置时间，程序保存等待状态，重置后继续；期间也可以暂停或关机。登录失效等需要人工处理的情况会保留检查点并给出错误。

## 重建本机的 GPU 编码环境

本机验证使用 Python 3.12、RTX 4060 Laptop 和 CUDA 12.4 版 PyTorch。需要在同一台机器上重建时，在项目根目录将以下包安装到新建的独立环境。其余依赖通过 `project-base.pth` 使用项目现有版本。

```powershell
.\.venv\Scripts\python.exe -m venv --without-pip .venv-bge-gpu
Set-Content -Encoding ascii .venv-bge-gpu/Lib/site-packages/project-base.pth (Resolve-Path .venv/Lib/site-packages).Path
.\.venv\Scripts\python.exe -m pip install --no-deps --target .venv-bge-gpu/Lib/site-packages --index-url https://download.pytorch.org/whl/cu124 torch==2.6.0+cu124 torchvision==0.21.0+cu124
```
