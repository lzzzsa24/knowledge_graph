## 新增返回字段

`evidence_qualifications` 为数组，每条含 `id`、`kind`、`status`、`pdf_pages`、`claim_ids`、`summary`、`usage_limit`、`evidence`。`kind` 为 `transcription_correction`、`source_conflict` 或 `source_limit`。

- `active`：原 PDF 的实际 SHA、目录 SHA、该文档原始知识记录摘要均匹配当前审查。展示摘要、适用限制和有页码的双侧依据。
- `stale`：来源或记录已变化。相关有效文字/数值停止参与回答，提示重新核验并保留原 PDF 入口。该提示不是新的文献结论。
- `disputed_value`：存在单值争议时，有效记录的 `value_text`、`unit` 为空；不能回退原始字段补值。
- `related_claim_only`：复核与某知识记录相关，但不能把整篇定性观察一起禁用。Kim p10 与 p5/p6/p12 的范围不同。

完整字段随 `/api/claims`、`/api/search`、阅读版、问答来源、创新来源、研究地图及网络详情返回。`/api/research-map`、`/api/research-network` 还有按文档组织的顶层资格记录。紧凑的 `/api/research-graph` 总览只附 `id/kind/status/pdf_pages`；完整内容从已有详情接口取得，以维持 150,000 字节总览预算。

前端可在结果旁显示短提示，点击展开来源页和使用限制。不建议在所有答案前统一加“按本次证据”等套话。原文冲突应展示在对应数字/结论旁。

## 检索与缓存

复核页可用人工审阅的 `query_aliases` 定位。每个内层数组要求词组同时出现，外层数组任一匹配即可；NFKC、大小写及空白归一。单个普通概念或数字不足以跨文档选定研究。显式别名也可召回有适用限制的原页，例如Theil照片图注；自动同组补页只用于 `source_conflict`，单位恢复条目不自动展开全部修复页。

PDF 或知识记录变化会使复核失效；地图缓存包含资格文件和绑定 PDF 的物理版本。验证旧地图的签名仍使用原始知识记录，投影字段不参与签名。原有 snapshot、ETag 和详情版本检查保持。
